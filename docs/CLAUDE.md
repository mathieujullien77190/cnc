# docs/

Documentation de référence, en français.

| Fichier | Contenu |
|---|---|
| `FORMAT.md` | Le format `.cutparts.json` (`cnc-parts`) : pièces 2D, trous, `labels`, `rotate`, quantités |
| `cutparts.schema.json` | Schéma JSON de ce format |
| `MODELES.md` | Les modèles 3D : format `cnc-model`, planches, repères, actions, envoi à la découpe, API `window.cnc3d` |

Règles :
- Mettre à jour la doc dans le même changement que le code qu'elle décrit. Les règles de travail sont dans les `CLAUDE.md` et les skills (`.claude/skills/`), pas ici.
- Pas de doc d'historique : la doc décrit l'état actuel.
