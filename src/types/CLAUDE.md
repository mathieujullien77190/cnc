# src/types/

Types partagés entre plusieurs composants ou domaines : `Tab`, `SheetEntry`, `ImportReport`, `View`, `SheetViewState`. Les types du cœur (`Part`, `Sheet`…) sont dans `src/core/types.ts`, ceux des modèles dans `src/models/types.ts`, ceux de chaque composant dans son `types.ts`. Préférer `type` à `interface`.
